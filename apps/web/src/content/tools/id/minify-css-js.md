## File lebih kecil, website lebih cepat

Setiap kilobyte yang dihemat mempercepat waktu muat, terutama di jaringan seluler. Minify adalah
langkah paling sederhana untuk memperkecil CSS dan JavaScript sebelum dipasang di website.
