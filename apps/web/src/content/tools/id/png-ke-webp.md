## PNG yang lebih ringan untuk website

PNG bagus untuk gambar dengan transparansi, tapi ukurannya besar. WebP menyimpan transparansi
yang sama dengan file jauh lebih kecil, sehingga logo, ikon, dan tangkapan layar di website
dimuat lebih cepat.
