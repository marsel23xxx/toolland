## Semua tabel statistik untuk skripsi di satu tempat

Uji validitas, uji t, uji F, dan uji chi-square selalu membutuhkan nilai tabel sebagai
pembanding. Daripada mencari file PDF tabel yang barisnya terbatas, tool ini menghitung nilai
tabel untuk df dan taraf signifikansi berapa pun.

## Tabel yang tersedia

- **Tabel r product moment**: untuk uji validitas kuesioner dan uji korelasi Pearson. Baris
  memakai df = N − 2, dengan kolom N yang membantu.
- **Tabel t**: untuk uji t sampel, uji beda, dan uji parsial regresi.
- **Tabel F**: untuk uji F simultan regresi dan ANOVA, dengan α 0,10, 0,05, 0,025, dan 0,01.
- **Tabel chi-square**: untuk uji independensi dan uji kecocokan.

## Bandingkan dengan nilai hitung

Isi nilai hitung dari SPSS atau Excel. Tool ini langsung menyimpulkan apakah hasilnya signifikan
(H₀ ditolak) dan menampilkan nilai p, sehingga kamu tidak salah membaca arah perbandingannya.
