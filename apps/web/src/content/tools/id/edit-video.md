## Editor video ringan tanpa instalasi

Untuk kebutuhan sehari-hari seperti menggabungkan beberapa klip dari HP, membuang bagian yang
tidak perlu, memberi judul atau keterangan, dan menambahkan musik latar, kamu tidak perlu
aplikasi berat. Semua bisa dilakukan di browser, dan hasilnya MP4 yang siap dibagikan ke WhatsApp,
Instagram, TikTok, atau YouTube.

## Simpan progres dengan file .ayu

Editing belum selesai? Simpan proyek sebagai file **.ayu** lalu buka lagi kapan saja. Pilih
**Ringan** bila video aslinya tetap ada di perangkat yang sama, atau **Beserta video** bila ingin
melanjutkan di perangkat lain. Toolland tidak menyimpan apa pun di server, jadi file .ayu adalah
satu-satunya salinan proyekmu.
