## Kapan memakai kompresi maksimal

Bila Kompres PDF di browser belum cukup kecil, misalnya PDF berisi grafik vektor rumit, banyak font,
atau hasil ekspor dari aplikasi desain, Ghostscript bisa menyusun ulang seluruh isi PDF menjadi jauh
lebih ringkas.
