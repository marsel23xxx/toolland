## No more checking page by page

Thesis handbooks set many rules at once: margins, fonts, spacing, chapter titles, page
numbering, even where table captions go. Checking hundreds of pages by hand is tiring and easy to
get wrong. This tool reads the whole document and points out every part that does not match.

## How the check works

Each paragraph is recognized by type: chapter titles ("CHAPTER 1" or "BAB I"), front matter
titles (PREFACE, TABLE OF CONTENTS), subheadings (1.1 or A.), body text, numbered lists, table and
figure captions, table cells, and references. Each type is checked with its own rules. References
are only checked for font and size, since their spacing is often set differently.

## Tips before uploading

1. **Put chapter titles on their own line**, such as "CHAPTER 1" followed by the title.
2. **Use Word's automatic table of contents.** After fixing, update it with right-click → Update
   Field.
3. **Keep a backup of the original.** The fixed file downloads separately, but a backup never
   hurts.
