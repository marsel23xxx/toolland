## Who is this template for?

For project managers, IT and creative teams, event committees, contractors, and students working
on team projects. List your tasks and durations: the Gantt chart, status, and dashboard build
themselves, and you can see right away which tasks are late.

## How it works

Each task has a start date, or starts automatically after its predecessor ends. End dates use
working days, so weekends and holidays are skipped. The Gantt chart is drawn with conditional
formatting, so the file stays light even with many tasks.

## Scheduling tips

- Break big tasks into 1-10 day tasks so progress is easy to measure.
- Give every task one owner.
- Check the Workload sheet: if someone has 3 or more tasks in the same week, rebalance.
